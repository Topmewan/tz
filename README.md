# Локальные заметки

Небольшое SPA для создания и редактирования заметок со списками задач. Приложение работает в браузере, хранит заметки локально и не требует серверной базы данных.

## Стек

- Nuxt 4 в SPA-режиме, Vue 3 Composition API и TypeScript strict
- Pinia для состояния заметок
- SCSS и собственные доступные UI-компоненты
- Vitest для unit-тестов
- Ручное сохранение в localStorage без плагинов персистентности и библиотек Undo/Redo

## Запуск локально

Требуется Node.js 22.22 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Nuxt в терминале (обычно http://localhost:3000).

Полезные команды:

```sh
npm run test:unit
npm run typecheck
npm run build
npm run preview
```

## Запуск через Docker

Из корня проекта выполните:

```sh
docker compose up --build
```

Приложение будет доступно по адресу http://localhost:3000. Остановить контейнер можно сочетанием Ctrl+C; для фонового запуска добавьте флаг `-d`.

## Возможности и UX

- Главная показывает заметки и несколько первых пунктов списка без интерактивных чекбоксов.
- Редактор позволяет менять название, добавлять и удалять пункты, отмечать их выполненными.
- Пустое название разрешено и отображается как «Без названия». Пустые пункты удаляются при сохранении, а редактор сообщает об этом.
- Отмена и удаление подтверждаются доступной модалкой. Она поддерживает клавиатурный фокус, Escape и возврат фокуса к вызывающему элементу.
- Прямой переход к неизвестному ID показывает сообщение «Заметка не найдена».
- Если заметка удалена в другой вкладке во время редактирования, редактор закрывает сессию и блокирует повторное сохранение этой заметки.
- Незавершённый черновик сохраняется отдельно. При следующем открытии подходящей заметки приложение предлагает восстановить его; конфликтный черновик можно удалить.

## История Undo/Redo

История существует только в текущей сессии редактирования и хранит атомарные команды/дельты: изменение текста, добавление или удаление пункта, изменение состояния чекбокса. Полные копии заметки в истории не сохраняются.

Последовательный ввод в одном поле объединяется в одну запись после паузы или при потере фокуса. Для остальных действий создаётся отдельная запись. Новое действие после Undo очищает ветку Redo; глубина истории ограничена 50 шагами. Сохранение и отмена редактора завершают сессию и очищают историю.

На странице редактора доступны Ctrl/Cmd+Z для Undo и Shift+Ctrl/Cmd+Z для Redo. В полях ввода эти клавиши остаются нативной историей браузера.

## Хранение данных

Сохранённые заметки и черновик находятся в отдельных ключах localStorage:

- `tz.notes.v1` — заметки и время сохранения
- `tz.draft.v1` — незавершённый черновик

Каждый объект содержит `schemaVersion: 1`. Данные проверяются при чтении до передачи в Pinia. Изменения записываются с задержкой, а не на каждый символ. Версия схемы и ручная сериализация упрощают явную проверку будущих изменений формата.

## Структура

- `pages/` — список заметок и экран создания/редактирования
- `components/ui/` — базовые кнопки, поля, чекбокс и модальное окно
- `components/notes/` — карточки заметок и редактор списка задач
- `composables/` — сессия редактирования, горячие клавиши, модальные сценарии и persistence lifecycle
- `stores/` — Pinia store заметок
- `utils/history/` — команды Undo/Redo
- `utils/storage/` — проверка, сериализация и синхронизация localStorage
- `tests/unit/` — тесты истории, store, persistence и межвкладочных сценариев
