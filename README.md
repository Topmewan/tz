# tz

Стартовый каркас SPA на Nuxt, Vue, TypeScript и Pinia.

## Запуск

Требуется Node.js 22.22 или новее.

```sh
npm install
npm run dev
```

## Команды

```sh
npm test
npm run typecheck
npm run build
```

## Docker

```sh
docker compose up --build
```

Приложение будет доступно по адресу http://localhost:3000.

Каркас не содержит реализации приложения. Пункт 3 исходного задания был пустым, поэтому продуктовые функции пока не добавлялись.
